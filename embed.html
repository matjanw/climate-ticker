Climate Ticker

A compact, self-contained widget showing carbon released, heat trapped, and global warming since 1850 — ticking in real time. Drop it into any page or footer. No tracking, no cookies, no network calls.

Live preview

Option 1 — Web Component (recommended)

One script tag, one element. Styles are sealed inside a Shadow DOM, so it never clashes with your page. Re-theme it with CSS variables if you like. 

<script src="https://cdn.jsdelivr.net/gh/matjanw/climate-ticker@1.0.0/climate-ticker.js"></script>
<climate-ticker></climate-ticker>

Optional theming: climate-ticker { --cs-bg:#fff; --cs-text:#111; }

Option 2 — iframe (simplest, great for footers)

Total isolation, paste-and-go. Best when you can’t add a script tag (CMS footers, marketing pages). The little script lets the frame auto-resize to fit the widget — it adapts to the width you give it. 

<iframe id="climate-ticker" src="https://matjanw.github.io/climate-ticker/widget.html"
        width="100%" height="640" loading="lazy" scrolling="no"
        style="border:0;max-width:720px;display:block;margin:0 auto"
        title="Climate Ticker — real-time climate counters"></iframe>
<script>addEventListener('message',function(e){
  if(e.data&&e.data.type==='climate-ticker:resize'){
    var f=document.getElementById('climate-ticker');
    if(f)f.style.height=e.data.height+'px';
  }
});</script>

No-script builders (e.g. some Wix/Squarespace blocks): drop the <script> and keep a fixed height. Set the frame narrow for a stacked card, or wide (up to 720px) for a short, horizontal banner.

Hosting & pinning

  • Push the repo to GitHub — climate-ticker.js and widget.html are then served free via jsDelivr (cdn.jsdelivr.net/gh/matjanw/climate-ticker@TAG/…) or GitHub Pages.
  • Pin a version tag (e.g. @1.0.0) so embeds never break on an update.
  • For extra integrity, add a Subresource Integrity hash to the script tag: integrity="sha384-…" crossorigin="anonymous".
